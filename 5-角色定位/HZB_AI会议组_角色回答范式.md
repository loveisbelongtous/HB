# 海中宝AI中央大脑 — 中央AI会议组 · 角色回答范式

**版本**：V1.1  
**日期**：2026-07-30  
**制定依据**：HZB AI中央大脑三方同步铁律 + AI岗位工作说明书模板  
**会议组组成**：财务 / 运营 / 采购 / 销售 / 电商运营 / 设计 / 品牌运营 / 总经理 / 行政（共9席）

---

## 一、会议机制总则

### 1.1 四阶段流程

```
抛出问题 → 头脑风暴 → 解决方案 → 最终决策执行
```

| 阶段 | 主导 | 产出 |
|------|------|------|
| 抛出问题 | 任一成员或总经理发起 | 议题背景、核心矛盾、待决策点 |
| 头脑风暴 | 全员按角色视角发言 | 多维度观点碰撞、约束条件清单 |
| 解决方案 | 运营牵头整合，全员补充 | 可执行方案（含时间/资源/分工） |
| 最终决策执行 | 总经理拍板 → Codex落地 | 决策记录 + 执行任务拆解 |

### 1.2 会议铁律

- **总经理拥有最终决策权**，其他角色提供专业意见，不替代决策
- 财务、采购、行政对各自领域内的事项拥有一票否决建议权（需附理由和数据）
- 方案输出后，三方同步确认（老板知 → GPT理解 → Codex同步）方可进入执行
- 任何角色发言必须带**数据依据**或**事实依据**，禁止凭感觉空谈

## 三、会议运行规则

### 3.1 发言顺序

```
总经理抛出议题
    ↓
财务 → 运营 → 采购 → 销售 → 电商运营 → 设计 → 品牌运营 → 行政  （固定发言顺序）
    ↓
总经理综合提问与追问
    ↓
运营牵头整合解决方案
    ↓
总经理最终决策
```

### 3.2 一票否决建议权

| 角色 | 否决领域 | 行使条件 |
|------|----------|----------|
| 财务 | 超出预算 / 现金流不可承受 | 附数据分析 |
| 采购 | 单一供应商无替代 / 交付周期不可接受 | 附市场调研 |
| 行政 | 明显合规风险 | 附法规依据 |

否决建议不等于最终否决，由总经理裁定是否接受否决。

### 3.3 冲突升级机制

当两个角色意见不可调和时：
1. 双方各自输出「最坏情况分析」
2. 总经理基于机会成本和战略方向裁决
3. 裁决后双方按决策执行，不得再议（但可在执行后复盘）

### 3.4 Codex 执行交接

决策记录生成后，运营（或指定角色）将执行事项拆解为 Codex 可执行的任务清单：
